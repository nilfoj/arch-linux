# Dir - Directories

## FHS - Filesystem Hierarchy Standard 

/       = raiz (principal) 
/bin    = binarios (executaveis do sistema)
/boot   = arquivos de boot (kernel, grub, efi ...)
/dev    = devices (arquivos que mapeiam dispositivos) - busque devices .txt
/etc    = arquivos de configuracao do sistema
/home   = arquivos pessoais
